# DateSense – Expiry Detection Website

DateSense is a simple web application that helps users track product expiry dates.  
Users can enter the product name and expiry date, and the system automatically calculates how many days remain before the product expires.

## Features
- Add product name and expiry date
- Automatically calculates remaining days before expiry
- Stores product data for tracking
- Simple and clean user interface

## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase
